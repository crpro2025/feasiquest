# 🚀 Quick Access Guide - Response Viewer & Questionnaire

## 📍 Live Demo URLs

### 1. Response Viewer (For Sponsors/CROs)
**URL:** https://8050-759d638c-5f4d-4523-8093-6cc0b05d7b57.proxy.daytona.works/response-viewer-enhanced.html

**What it does:**
- View all site responses to feasibility questionnaires
- Filter by status, score, location
- Compare multiple sites side-by-side
- Export data to Excel
- Approve/reject responses
- Send messages to sites

**Quick Test:**
1. Open the URL
2. See 24 demo responses from 8 research sites
3. Try filtering by "Approved" status
4. Click "View Details" on Johns Hopkins (Score: 95)
5. Select 2-3 sites and click "Compare Selected"
6. Click "Export Excel" to download CSV

### 2. Questionnaire (For Research Sites)
**URL:** https://8050-759d638c-5f4d-4523-8093-6cc0b05d7b57.proxy.daytona.works/questionnaire-updated.html

**What it does:**
- Complete 50-question feasibility questionnaire
- 7 sections covering all aspects of site capabilities
- Upload documents (CV, certificates, photos)
- Auto-save every 60 seconds
- Preview responses before submission
- Track progress in real-time

**Quick Test:**
1. Open the URL
2. Fill out Section 1 (Site Information) - 7 questions
3. Watch progress bar update automatically
4. Click "Next Section" to go to Section 2
5. Try uploading a file in Section 7
6. Click "Preview" to see all your responses
7. Click "Save Draft" to save your progress

## 🎬 Demo Scenarios

## 💾 Data Persistence

### Response Viewer
- Demo data is hardcoded in JavaScript
- No backend required for testing
- All filtering/sorting happens client-side

### Questionnaire
- Auto-saves to localStorage every 60 seconds
- Data persists across page refreshes
- Manual save available via "Save Draft" button
- Clear localStorage to reset form

## 🔧 Troubleshooting

### Response Viewer Issues:
- **No responses showing:** Check browser console for errors
- **Filters not working:** Clear browser cache and reload
- **Export not working:** Check browser's download settings

### Questionnaire Issues:
- **Progress not updating:** Ensure JavaScript is enabled
- **Auto-save not working:** Check localStorage is enabled
- **File upload failing:** Check file size limits
- **Data not restoring:** Clear localStorage and start fresh
